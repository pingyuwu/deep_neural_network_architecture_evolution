
过去六十多年，研究者不断增加神经网络的深度、宽度和参数量，但很快发现，神经网络并不是一台可以无限堆叠零件的机器。

网络变深，可能出现梯度消失；网络变宽，可能增加大量计算成本；网络变大，训练可能不稳定；网络拥有更多参数，却不一定能够更有效地利用这些参数。

于是，研究者不得不不断改变网络的结构、信息传播方式、参数化方案和计算机制。

从感知机到多层神经网络，从 LSTM 到 ResNet，从 CNN 到 Transformer，再到 MoE，这些看似五花八门的架构创新，其实一直在回答一组相互关联的问题：

怎样让神经网络具备足够强的表达能力？
怎样让信息和学习信号在深层网络中顺畅传播？
怎样让越来越复杂的网络保持稳定、容易训练？
怎样在有限的计算资源下获得更强的模型能力？
怎样让网络中的不同部分有效交互，又不造成计算灾难？
怎样让小规模模型的经验能够迁移到大规模模型？
怎样从庞大的设计空间中找到真正有效、可以复用的架构规律？
这些问题并不是在某个时刻突然出现、解决之后就永远消失了。它们一直存在，只是在不同发展阶段，某些问题逐渐成为制约神经网络进一步发展的主要瓶颈。

本文想讲述的，就是这段历史背后的共同逻辑：

深度神经网络架构的发展，不只是模型规模不断增长的历史，更是一部不断发现、识别和解除系统性约束的历史。

更重要的是，我们能不能从这段历史中提炼出一套设计原则，让未来的研究者不必每次都从零开始，在无数种网络结构和超参数中盲目试错？

答案是：可以尝试，而且已经出现了不少值得借鉴的理论与工程方法。
